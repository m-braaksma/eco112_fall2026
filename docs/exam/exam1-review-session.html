Chapter 1: The Budget Line, the PPF, and Factors of Production

viewof seedBL = Inputs.button("Generate New Numbers", {value: 0, reduce: x => x + 1})
paramsBL = {
  seedBL;
  const Px = randInt(4, 12);
  const Py = randInt(4, 12);
  const maxX = randInt(10, 30);
  const I = Px * maxX;
  const maxY = Math.round((I / Py) * 10) / 10;
  const slope = Math.round((-Px / Py) * 100) / 100;
  const xTest = randInt(2, maxX - 1);
  const yTest = randInt(2, Math.max(Math.round(maxY) - 1, 2));
  const costTest = Px * xTest + Py * yTest;
  return { Px, Py, maxX, I, maxY, slope, xTest, yTest, costTest };
}
md`A consumer has $${paramsBL.I} to spend on two goods: X (price $${paramsBL.Px} each) and Y
(price $${paramsBL.Py} each).

**a)** If the consumer spends everything on X, how many units of X can they buy?

<details><summary>Show solution</summary>

$${paramsBL.I} / $${paramsBL.Px} = ${paramsBL.maxX} units of X.

</details>

**b)** If the consumer spends everything on Y instead, how many units of Y can they buy?

<details><summary>Show solution</summary>

$${paramsBL.I} / $${paramsBL.Py} ≈ ${paramsBL.maxY} units of Y.

</details>

**c)** What is the slope of this consumer's budget line, and what does it represent
economically?

<details><summary>Show solution</summary>

Slope = −Px/Py = −${paramsBL.Px}/${paramsBL.Py} ≈ ${paramsBL.slope}. It represents the
rate at which the consumer must give up Y to get one more unit of X, the opportunity cost of X
in terms of Y, given these prices.

</details>

**d)** Can this consumer afford ${paramsBL.xTest} units of X and ${paramsBL.yTest} units of Y at
the same time?

<details><summary>Show solution</summary>

Cost = ${paramsBL.Px}(${paramsBL.xTest}) + ${paramsBL.Py}(${paramsBL.yTest}) =
$${paramsBL.costTest}. ${
  paramsBL.costTest < paramsBL.I
    ? `Since this is less than $${paramsBL.I}, the bundle is **attainable**, with money left over.`
    : paramsBL.costTest === paramsBL.I
      ? `Since this equals exactly $${paramsBL.I}, the bundle sits **exactly on the budget line**.`
      : `Since this exceeds $${paramsBL.I}, the bundle is **unattainable**.`
}

</details>`

paramsPPF = {
  seedPPF;
  const step = randInt(4, 10);
  const c1 = randInt(1, 4);
  const c2 = c1 + randInt(1, 4);
  const B0 = randInt(30, 60);
  const B1 = B0 - c1;
  const B2 = B1 - c2;
  return { step, c1, c2, B0, B1, B2 };
}
md`A country can produce Tents or Canoes. Its PPF passes through these points:

| Point | Tents | Canoes |
|---|---:|---:|
| A | 0 | ${paramsPPF.B0} |
| B | ${paramsPPF.step} | ${paramsPPF.B1} |
| C | ${paramsPPF.step * 2} | ${paramsPPF.B2} |

**a)** Moving from point A to point B, how many Canoes does the country give up in order to make
${paramsPPF.step} more Tents?

<details><summary>Show solution</summary>

${paramsPPF.B0} − ${paramsPPF.B1} = ${paramsPPF.c1} Canoes.

</details>

**b)** Moving from point B to point C, how many Canoes does the country give up this time?

<details><summary>Show solution</summary>

${paramsPPF.B1} − ${paramsPPF.B2} = ${paramsPPF.c2} Canoes.

</details>

**c)** Your answers to (a) and (b) aren't the same. What's going on, economically, and what is
this pattern called?

<details><summary>Show solution</summary>

The cost per step rises (${paramsPPF.c1} Canoes, then ${paramsPPF.c2} Canoes). This is the law
of increasing opportunity cost: resources aren't equally well suited to producing both goods, so
as more resources shift toward Tents, the ones reassigned are progressively less suited to Tents
(and more suited to Canoes), raising the cost of each additional Tent.

</details>

**d)** A new fishing-net material is invented that only helps build Canoes, it does nothing for
Tent-making. Describe what happens to this country's PPF.

<details><summary>Show solution</summary>

The Canoe-axis intercept rises (more Canoes possible if all resources go to Canoes). The
Tent-axis intercept is unchanged, since the new material doesn't touch Tent production. The PPF
pivots outward, anchored at the Tent-axis endpoint.

</details>

**e)** Now instead, imagine a general improvement, better transportation, say, that helps the
country produce *both* Tents and Canoes more efficiently. How would the resulting shift in the
PPF look different from part (d)?

<details><summary>Show solution</summary>

Both axis intercepts would rise together: the entire curve shifts outward, rather than pivoting
from one fixed point. This is the more typical picture of general economic growth, more of
*everything* is attainable, not just more of one good.

</details>`

Chapter 3: Supply and Demand

md`**Warm-up.** In your own words: why does the law of demand say quantity demanded falls as
price rises? What does the demand curve's downward slope represent?

<details><summary>Show solution</summary>

As a good's price rises, it becomes more expensive relative to substitutes, and buyers'
purchasing power effectively shrinks, so they buy less of it (and more of cheaper alternatives).
The downward-sloping demand curve is a picture of this: price and quantity demanded move in
opposite directions, holding everything else about the market fixed.

</details>`
viewof seedSD = Inputs.button("Generate New Numbers", {value: 0, reduce: x => x + 1})
paramsSD = {
  seedSD;
  const Pstar = randInt(8, 40);
  const Qstar = randInt(60, 180);
  const b = randInt(2, 6);
  const d = randInt(2, 6);
  const a = Qstar + b * Pstar;
  const c = Qstar - d * Pstar;
  const testOffset = randInt(2, 8);
  const testBelow = randInt(0, 1) === 0;
  const testP = testBelow ? Pstar - testOffset : Pstar + testOffset;
  const QdTest = a - b * testP;
  const QsTest = c + d * testP;
  const k = randInt(2, 6);
  const cNew = c - (b + d) * k;
  const PnewS = Pstar + k;
  const QnewS = Qstar - b * k;
  const j = randInt(2, 6);
  const aNew = a + (b + d) * j;
  const PnewD = Pstar + j;
  const QnewD = Qstar + d * j;
  const floorOffset = randInt(3, 8);
  const floorP = Pstar + floorOffset;
  const QdFloor = a - b * floorP;
  const QsFloor = c + d * floorP;
  return { Pstar, Qstar, a, b, c, d, testP, QdTest, QsTest, cNew, PnewS, QnewS, aNew, PnewD, QnewD, floorP, QdFloor, QsFloor };
}
md`A market has:

Qd = ${paramsSD.a} − ${paramsSD.b}P

Qs = ${paramsSD.c} + ${paramsSD.d}P

**a)** Find the price and quantity where this market clears, where quantity demanded equals
quantity supplied.

<details><summary>Show solution</summary>

Setting Qd = Qs: ${paramsSD.a} − ${paramsSD.b}P = ${paramsSD.c} + ${paramsSD.d}P, so P =
$${paramsSD.Pstar} and Q = ${paramsSD.Qstar}.

</details>

**b)** If the price were instead stuck at $${paramsSD.testP}, how much would buyers want to
buy and how much would sellers want to sell? Would this leave a shortage or a surplus, and how
big?

<details><summary>Show solution</summary>

Qd = ${paramsSD.QdTest}, Qs = ${paramsSD.QsTest}. ${
  paramsSD.QsTest > paramsSD.QdTest
    ? `Sellers want to sell more than buyers want to buy, a **surplus** of ${paramsSD.QsTest - paramsSD.QdTest} units.`
    : `Buyers want to buy more than sellers want to sell, a **shortage** of ${paramsSD.QdTest - paramsSD.QsTest} units.`
}

</details>

**c)** Production costs rise, changing the supply relationship to Qs = ${paramsSD.cNew} +
${paramsSD.d}P (demand is unaffected). Find the new market-clearing price and quantity. Has the
supply curve shifted, or has the market just moved along it? What about demand?

<details><summary>Show solution</summary>

New equilibrium: P = $${paramsSD.PnewS}, Q = ${paramsSD.QnewS}. The cost increase changes
the supply relationship itself, a **shift of the supply curve**. Demand never changed, only the
price did, so that's a **movement along** the demand curve.

</details>

**d)** Starting over from the *original* supply curve, suppose buyer demand instead changes to
Qd = ${paramsSD.aNew} − ${paramsSD.b}P. Find the new market-clearing price and quantity. Which
curve shifted, and which one just saw a movement along it this time?

<details><summary>Show solution</summary>

New equilibrium: P = $${paramsSD.PnewD}, Q = ${paramsSD.QnewD}. This time it's a **shift
of the demand curve**, while supply is unchanged, so that's a **movement along** the supply
curve.

</details>

**e)** Instead of a cost change, suppose the government sets a *price floor* at
$${paramsSD.floorP} (above the original equilibrium price), using the *original* supply and
demand curves. How much would be demanded and how much would be supplied at that price? Is there
a shortage or a surplus?

<details><summary>Show solution</summary>

Qd = ${paramsSD.QdFloor}, Qs = ${paramsSD.QsFloor}. Since Qs > Qd, there's a
**surplus** of ${paramsSD.QsFloor - paramsSD.QdFloor} units. This is exactly why price floors
(like a minimum wage) tend to create surpluses, unsold goods, or unemployed workers, rather than
shortages.

</details>`

Chapter 7: GDP, Real GDP, and Per Capita

viewof seedGDP = Inputs.button("Generate New Numbers", {value: 0, reduce: x => x + 1})
paramsGDP = {
  seedGDP;
  const C = randInt(60, 120) * 10;
  const Ig = randInt(10, 25) * 10;
  const G = randInt(15, 30) * 10;
  const X = randInt(6, 15) * 10;
  const M = randInt(8, 18) * 10;
  const Xn = X - M;
  const nominal = C + Ig + G + Xn;
  const indexOptions = [100, 102, 104, 105, 108, 110, 120];
  const index = indexOptions[randInt(0, indexOptions.length - 1)];
  const real = Math.round((nominal / (index / 100)) * 100) / 100;
  const population = randInt(20, 60);
  const perCapita = Math.round((real / population) * 1000) / 1000;
  return { C, Ig, G, X, M, Xn, nominal, index, real, population, perCapita };
}
md`This year, a country's spending adds up to: C = $${paramsGDP.C}B, Ig =
$${paramsGDP.Ig}B, G = $${paramsGDP.G}B, exports of $${paramsGDP.X}B, and imports of
$${paramsGDP.M}B. The GDP price index is ${paramsGDP.index} (base year = 100), and the
population is ${paramsGDP.population} million.

**a)** Find net exports, then use the expenditure approach to find nominal GDP.

<details><summary>Show solution</summary>

Net exports = ${paramsGDP.X} − ${paramsGDP.M} = $${paramsGDP.Xn}B. Nominal GDP =
${paramsGDP.C} + ${paramsGDP.Ig} + ${paramsGDP.G} + (${paramsGDP.Xn}) =
$${paramsGDP.nominal}B.

</details>

**b)** Strip out the effect of rising prices to find real GDP.

<details><summary>Show solution</summary>

Real GDP = ${paramsGDP.nominal} / (${paramsGDP.index}/100) ≈ $${paramsGDP.real}B.

</details>

**c)** Spread that real output across the population. What's real GDP per person?

<details><summary>Show solution</summary>

Real GDP per capita = ${paramsGDP.real}/${paramsGDP.population} ≈
$${paramsGDP.perCapita} thousand per person.

</details>

**d)** Next year, total real GDP doesn't change at all, but the population grows. What happens
to real GDP per capita, and why?

<details><summary>Show solution</summary>

It **falls**: the same total output now has to stretch across more people. This is exactly why
total growth and per-capita growth can tell different stories.

</details>`

Chapter 9: Unemployment and Inflation

Unemployment

viewof seedUE = Inputs.button("Generate New Numbers", {value: 0, reduce: x => x + 1})
paramsUE = {
  seedUE;
  const employed = randInt(40, 70) * 1000;
  const unemployed = randInt(2, 6) * 1000;
  const notInLF = randInt(15, 30) * 1000;
  const laborForce = employed + unemployed;
  const population = laborForce + notInLF;
  const urRate = Math.round((unemployed / laborForce) * 10000) / 100;
  const lfpr = Math.round((laborForce / population) * 10000) / 100;
  return { employed, unemployed, notInLF, laborForce, population, urRate, lfpr };
}
md`A region has ${paramsUE.population.toLocaleString()} adults: ${paramsUE.employed.toLocaleString()}
have jobs, ${paramsUE.unemployed.toLocaleString()} don't have a job but are actively looking, and
${paramsUE.notInLF.toLocaleString()} are retired, in school, or otherwise not looking for work.
